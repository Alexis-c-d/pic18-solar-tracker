# PIC18 Solar Panel Positioning System

Embedded system that orients a solar panel using light sensors, on a **PIC18F45K22**.

## Features
- LDR light sensing via ADC
- Servo positioning with CCP1 PWM
- Wind sensor read through CCP2 capture
- Keypad input and LCD display

## Toolchain
MPLAB X IDE · XC8 · Proteus (simulation)
